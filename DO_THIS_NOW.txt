❌ IF SOMETHING GOES WRONG:
──────────────────────────

"API key not valid" error:
→ You have the template file, not the real one
→ Go back and download from Firebase Console
→ Make sure it has your real project credentials

"Gradle sync failed" error:
→ google-services.json might be in wrong location
→ Delete it
→ Re-download and re-add
→ Sync again

"File not found" error:
→ File is not in app/ folder
→ Move it: C:\Users\anura\AndroidStudioProjects\Hana\app\
→ Sync again

"BUILD FAILED" error:
→ Check the Build tab for specific error
→ Usually Firebase/Google Services issue
→ Verify google-services.json is present
→ Try: Build → Clean → Rebuild again

Login doesn't work:
→ Check if test user exists in Firebase Console
→ Try signing up first instead of logging in
→ Check your Firebase project is correct
