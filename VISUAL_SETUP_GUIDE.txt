   → Go back to Firebase Console and re-download
   → Make sure file has real values (not "YOUR_PROJECT_ID")

Error: "Gradle sync failed"
   → File is in wrong location or corrupted
   → Delete the file
   → Re-download from Firebase Console
   → Add again

Error: "File not found"
   → File is in wrong folder (not in app/)
   → Move to: C:\Users\anura\AndroidStudioProjects\Hana\app\
   → Sync again

Error: "BUILD FAILED"
   → google-services.json missing
   → Add the file
   → Clean and rebuild

Error: "Plugin not found"
   → google-services.json not in app/ folder
   → Add it
   → Sync gradle
